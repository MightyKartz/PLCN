# Windows / macOS 桌面体验实施计划

日期：2026-09-16。分支：`codex/desktop-experience`。

本轮 goal：普通用户双击打开 PLCN，选择设备并预览修复；配置不依赖安装目录，能够管理数据更新、任务和列表恢复。沿用 Python 核心与现有浏览器界面。

| 阶段 | 交付 | 验收 | 状态 |
| --- | --- | --- | --- |
| 0 基础成果 | 上轮安全写回、数据包和图片解析独立提交；创建草稿 PR | 保留历史，PR 可审阅 | 进行中 |
| 1 跨平台路径 | 资源只读、用户数据/缓存分离、旧配置及人工规则迁移 | 从任意工作目录启动；升级不覆盖用户配置；迁移幂等 | 待开始 |
| 2 启动与使用 | 桌面无控制台入口、单实例、明确退出、系统选择器、首次引导/继续上次目录、收起高级选项 | 双击重复启动复用服务；任务运行时不误退出；目录选择可退回内置浏览 | 待开始 |
| 3 数据与任务 | 数据包界面：检查/获取/比较/启用/回滚；任务取消与失败图片重试；本地写回历史和恢复 | 更新不自动启用；取消保留已完成步骤；恢复前检查外部变化并备份当前文件 | 待开始 |
| 4 平台交付 | Windows 安装包、macOS app/dmg、明确架构、签名配置、测试/文档、PR 完成 | 本机测试与 Windows 打包冒烟；远端 CI 检查；签名和实机边界明确 | 待开始 |

安全边界：取消为协作取消，不中断原子写回/远端替换；恢复首先支持本地列表，ADB 备份仍保留在设备并提供说明。关闭浏览器标签不等于停止服务，界面提供退出入口。数据包更新不执行下载来的程序。不会自动合并 PR 或发布 Release。

macOS 签名、公证需要用户自己的 Developer ID 与 Apple 凭据；Windows 签名需要证书。代码与 CI 可准备流程，缺少凭据时不得声称产物已签名或正式分发就绪。无 macOS 本机时以 CI 构建和说明为界，仍保留人工 Gatekeeper/安装/文件选择验收。
