# UI 精简实施计划

目标：用户沿“选择游戏库 → 预览变更 → 应用并查看结果”完成任务，人工确认、备份恢复和失败重试始终可发现。

分支：`codex/ui-simplification`。基于尚未合并的 PR #5 (`codex/desktop-experience`)，新 PR 以该分支为 base；本次不合并任何 PR。

## 1. 状态与操作条件
- [ ] 移除写死的完成状态，根据扫描、列表、预览和运行状态显示流程。
- [ ] 无输入、无有效选择、请求运行中时禁用对应操作，防止重复提交。
- [ ] 输入、模式或数据源改变后清除过期预览；保留人工确认约束。

## 2. 首次引导与工作区
- [ ] 合并目录入口，选择目录后扫描；保留最近目录、自动检测和手动路径。
- [ ] 空库只展示引导；有列表后显示工作区；选中条目时显示详情。
- [ ] 合并统计与筛选，默认全部/可应用/待确认，其他筛选按需展开。
- [ ] 显示带数量的应用按钮，进度仅在运行或已有结果时展开。

## 3. 设置与管理
- [ ] 移除禁用的策略开关及重复图片模式选项；路径设置保持可访问。
- [ ] 精简顶部入口，保留任务、恢复入口；管理导航明确当前页。
- [ ] 数据来源使用可理解的状态描述，路径折叠；更新和比较结果留在当前面板。
- [ ] 完善中文/英文、焦点样式、标签、窗口缩放与暗色样式。

## 4. 验证与交付
- [ ] 用行为测试覆盖初始/扫描/预览/人工确认/运行/失败/取消的状态条件。
- [ ] 全量 Python 回归、JavaScript 检查、编译检查和差异检查。
- [ ] 使用隔离测试库进行浏览器验证：引导、预览、确认应用、结果、历史恢复；桌面和窄窗口截图。
- [ ] 创建 PR，检查远端 CI 并记录结果及实机验证边界。

验收：空库无错误绿色勾、无空统计；每阶段主操作明确；设置变化不会沿用旧预览；确认弹层与备份恢复保留。Windows 浏览器实测不代表 macOS 原生选择器或完整读屏验收。
