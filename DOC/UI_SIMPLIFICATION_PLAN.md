# UI 精简实施计划

目标：用户沿“选择游戏库 → 预览变更 → 应用并查看结果”完成任务，人工确认、备份恢复和失败重试始终可发现。

分支：`codex/ui-simplification`。基于尚未合并的 PR #5 (`codex/desktop-experience`)，新 PR 以该分支为 base；本次不合并任何 PR。

## 1. 状态与操作条件
- [x] 移除写死的完成状态，根据扫描、列表、预览和运行状态显示流程。
- [x] 无输入、无有效选择、请求运行中时禁用对应操作，防止重复提交。
- [x] 输入、模式或数据源改变后清除过期预览；保留人工确认约束。

## 2. 首次引导与工作区
- [x] 合并目录入口，选择目录后扫描；保留最近目录、自动检测和手动路径。
- [x] 空库只展示引导；有列表后显示工作区；选中条目时显示详情。
- [x] 合并统计与筛选，默认全部/可应用/待确认，其他筛选按需展开。
- [x] 显示带数量的应用按钮，进度仅在运行或已有结果时展开。

## 3. 设置与管理
- [x] 移除禁用的策略开关及重复图片模式选项；路径设置保持可访问。
- [x] 精简顶部入口，保留任务、恢复入口；管理导航明确当前页。
- [x] 数据来源使用可理解的状态描述，路径折叠；更新和比较结果留在当前面板。
- [x] 完善中文/英文、焦点样式、标签、窗口缩放与暗色样式。

## 4. 验证与交付
- [x] 用行为测试覆盖初始/扫描/预览/人工确认/运行/失败/取消的状态条件。
- [x] 全量 Python 回归、JavaScript 检查、编译检查和差异检查。
- [x] 使用隔离测试库进行浏览器验证：引导、预览、确认应用、结果、历史恢复；桌面和窄窗口截图。
- [x] 创建 PR #6 并完成 CI 检查；最终提交的检查状态以 PR 页面为准。

验收：空库无错误绿色勾、无空统计；每阶段主操作明确；设置变化不会沿用旧预览；确认弹层与备份恢复保留。Windows 浏览器实测不代表 macOS 原生选择器或完整读屏验收。

## 实施记录

- PR：[#6](https://github.com/MightyKartz/PLCN/pull/6)，依赖 #5。
- 状态规则集中到 `src/templates/workflow.js`；以输入签名校验预览有效性，异步操作串行化。进度连接中断时保持写入锁定并使用 EventSource 自动重连。
- 首页仅保留导入；扫描后左侧列出各主机全部列表，右侧预览。筛选自带计数，点击“全部”不会改变选择。
- 设置移入独立面板，操作模式成为图片开关的唯一来源。仅名称/仅图片模式的说明与实际行为一致。
- 数据管理支持当前页查看更新/比较结果，导航请求避免过期响应覆盖当前页。路径默认折叠。
- 本地回归：114 passed / 1 skipped；包含 13 个 Node 行为用例。跳过项需要仓库未提供的 Snatcher 本地数据。
- 交互验收：中文目录扫描；同一主机两个列表；预览期间操作禁用；待确认项不自动选择；键盘 Enter 打开详情；人工核对加入队列；切换模式清空旧预览；名称写回及原文件恢复；更新查询留在当前面板。
- 首次提交的全部 10 项 CI 已通过；后续修正同样执行本地回归，最终提交的 CI 状态记录于 PR。
- 截图保存在本地 `.plcn_runtime/ui-smoke/screenshots/`，测试库与配置全部隔离。未修改真实游戏库，也未替换用户已安装版本。
- macOS Intel/Apple Silicon 打包和回归由 CI 覆盖；macOS 实机原生选择器、VoiceOver 和签名不在本次验收结论内。

- 布局验收：1280×900 桌面、640×900 窄窗口，中英文、浅色/暗色；修复表格撑大父容器导致流程和筛选被裁切的问题。640px 下页面无横向溢出，仅 960px 表格在自身约 607px 容器内滚动。批量确认可取消且未启动任务。
