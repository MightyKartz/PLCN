## 2026-09-16 复核

- 复核时 #5 `dd987f3`、#6 `03451af` 各有 10 项 CI 通过，无代码审查或行内反馈。
- 检查了写回/恢复的文件摘要保护、工作区预览失效与操作锁定、管理操作、实例锁及打包入口。
- 发现 Windows 默认 HTTP 服务复用地址可能让不同配置的进程占用同一端口。改为 Windows 独占地址；端口占用时沿用随机空闲端口回退。加入实际 socket 绑定回归，保证第二个启用复用的服务也无法占用已运行实例的端口。
- 本地全量回归：116 passed / 1 skipped。跳过项依赖未提供的 Snatcher 数据。JavaScript 语法、Python 编译和差异检查通过。
- 新构建的 Windows 程序通过隔离配置的资源加载、同配置重复启动、不同配置双实例、端口隔离和正常退出验收。
- 本机 Setup 验收发现默认 `AllowNoIcons=no` 导致 `/NOICONS` 未生效，测试卸载删除了已有便携安装的开始菜单快捷方式；原程序未变，快捷方式已恢复。安装器现支持跳过图标，验收使用独立程序组并保护已有快捷方式，发现变化会还原并使检查失败。
- 修正 Windows 卸载程序返回后仍短暂占用日志、导致验收临时目录清理失败的竞态；仅对 Windows 共享/访问错误做有限重试。
