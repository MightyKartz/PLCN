# 阶段 1C：预览状态契约与第一阶段验收

## 本次范围

统一现有扫描与名称／图片修复预览的范围说明、身份依据、图片状态、筛选和所选统计。阶段 1A 的管理标识贯穿浏览与修复预览；不新增多盘分组、M3U、文件移动或转换。扫描方案仍只确认增量列表，更新后再分析名称与图片方案；未分析的后续操作不伪装为零变更或已完成。跨操作的文件事务与恢复留待对应操作阶段。

## 服务端身份来源

`analyze_playlist` 的提案新增 `game_id`、`disc_id`、`content_id`，与相同列表、主机范围的浏览响应一致。MTP 使用原设备 URI 绑定，不能使用临时下载文件路径；行内不同 `db_name` 不能改写所选列表的身份范围。原快照、单项核心、中文名、人工图片记录与原应用接口保留。

提案新增 `identity`：`state`、`requires_review`、`source`、`translation_source`、`evidence`、`conflicts`、`release_verified`。优先显示冲突，其次人工规则；模糊、跨系统译名、父目录推测或多个不同游戏的候选不得因封面源存在升级为确定身份。

| state | 含义 | 默认处理 |
| --- | --- | --- |
| conflict | 已有证据链存在冲突 | 等待核对 |
| confirmed_rule | 已有人工规则命中 | 允许进入所选方案 |
| candidate | 模糊、跨系统或未证实来源 | 等待核对 |
| checksum_match | 已有校验值证据关联标准名 | 允许进入所选方案 |
| database_title | DAT 标准名称 | 允许进入所选方案 |
| exact_title | 精确名称／别名命中 | 允许进入所选方案 |
| title_family | 已识别名称家族，版本仍可能不确定 | 按受约束封面候选继续 |
| unresolved | 身份尚未识别 | 等待核对 |

`release_verified` 当前始终为 false：本轮不新读 ROM 全量校验，名称、列表声明的校验值、UUID 与图片推荐都不是“本次已验证 ROM 内容”的证明。悬停依据显示已有证据，不伪造地区、修订或盘号。

## 人工选择与图片推荐

“采用此名称”或编辑名称记录本次明确的人工名称选择；它只影响当前提案，不验证 ROM 版本，也不自动保存长期规则。单独改图片源不确认模糊的游戏名称。全部主机补全在服务端跳过待核对身份及图库查询失败／未找到源的项，避免绕过单主机预览限制。

已有图片与人工图片选择继续使用原机制。封面推荐仅在服务端身份不要求复核且候选已受版本约束时发生；保留原图库 ambiguous 状态，以 `artwork_recommended` 标示当前图片选择，不改写为已确认身份。

## 当前状态的唯一投影

- `previewArtworkState` 从当前提案、图片读取与任务结果派生封面状态；标签和“图片待处理”筛选共用它。
- 已有有效本地图片优先保留；失败下载、图库查询失败、当前名称未识别和未匹配图片源分别展示。
- `buildRepairPreviewSummary` 汇总当前可选项、勾选项、名称修改、补图及待处理原因；筛选数量与范围摘要使用同一投影。
- 配置变化后旧预览不能回填；人工编辑和应用结果只更新当前提案，统计随当前结果重新派生。
- 扫描摘要显示新增／保留／跳过，并说明未执行名称图片分析；修复摘要说明保留游戏文件与单项核心。未实现的分组、路径变化不显示为已经分析的零变更。
