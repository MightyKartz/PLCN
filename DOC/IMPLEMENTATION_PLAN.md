# PLCN 分阶段实施计划

开始日期：2026-09-16。基线：`0dfc8a0`，76 passed / 1 skipped。

目标：让中文名称、游戏身份和图片查找各自可解释；所有入口采用一致的安全写回规则；数据可以更新，用户校正可以长期保留。

## 执行顺序与验收

| 阶段 | 工作 | 验收条件 | 状态 |
| --- | --- | --- | --- |
| 1 写回安全 | 保留全部原始条目、统一人工复核规则、严格 CRC 覆盖、原子保存、并发互斥、过期快照检测 | 同名不同 ROM 不丢失；需复核项默认跳过；写入失败不截断原文件 | 已完成 |
| 2 本地服务与设备 | 仅回环监听、同源会话保护、并发 HTTP、不强杀端口进程；ADB 暂存、比较、备份、推送后读回 | 未授权请求不能读取/修改本地文件；SSE 不阻塞请求；设备变化或推送失败不报告成功 | 已完成；ADB 为模拟验证 |
| 3 数据模型与数据包 | 按系统隔离名称与别名、可迁移 schema、来源指纹、离线数据包构建/检查/切换、受控上游更新 | 跨系统同名可共存；空译名不伪装成功；数据切换可恢复且不覆盖人工校正 | 已完成 |
| 4 图片解析与逐条系统 | 独立 artwork resolver、统一文件名规则、分类型本地状态、图片有效性、旧图复用、下载失败分类；按条目 db_name 识别系统 | 混合列表使用正确平台；损坏图片可重试；改名复用旧图；源图片与显示名分离 | 已完成 |
| 5 集成与交付 | 前端接入复核确认和各类状态、开发/用户文档、完整测试与 UI 冒烟 | CLI/UI/批量规则一致；测试通过；交付中准确列出实机与跨平台未验证项 | 已完成 |

每阶段先完成可验证的实现与必要回归，再更新本文件。测试采用临时列表、离线 DAT 和模拟网络/ADB；不改动真实用户 ROM 或实机列表。不自动发布或推送 Git。

- 写回回归覆盖：重复条目保留、未核对项拒绝、全条目快照、CRC 冲突、原子写入失败、文件外部修改、协作锁。各入口共用 `apply_changes` 合约。
