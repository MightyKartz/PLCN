# 图形化游戏管理实施计划

参考：用户确认方向的概念图（DOC/design/game-management-concept.png）。以现有深色主题、蓝色重点色、左侧主机 SVG 图标与缩写为基础；页面布局和控件用原生 HTML/CSS 实现，不把概念图作为界面背景。

## 范围与步骤

1. **游戏浏览**：默认封面网格，保留详细列表切换；卡片展示封面、名称、缺图状态与多选框，点击卡片在右侧打开详情。搜索、主机、存储范围筛选继续生效。
2. **上下文管理**：多选工具栏位于游戏区顶部；右侧详情栏展示名称、主机、核心、存储位置、文件路径和大小。名称在栏内编辑并预览保存，保持 ROM 文件名和已有核心配置不变；封面操作复用现有封面工具。
3. **页面内导入**：“添加游戏”打开页面工作区，不使用导入对话框。来源区显示文件／目录，目标区选择主机和目录，中间展示预览及冲突状态；确认、取消、进度、结果在同一页面完成。系统原生文件选择器仅用于选取电脑文件。
4. **页面内移出**：单项与批量操作均在工作区列出将移出的条目，再确认修改。ROM、封面和存档保留；旧列表哈希阻止过期索引误改；列表修改复用已有事务备份与恢复。
5. **验证与交付**：临时目录验证导入、重复、冲突、BIOS、光盘配套引用、名称编辑、移出、过期预览、取消和恢复；浏览器验证网格／列表／详情／页面内导入、中英文、桌面与窄窗口。只在隔离测试库执行写入，不对真实掌机做验收写入。

## 布局与状态

- 左侧主机分类延续当前结构，不新增任务中心或管理导航。
- 中间游戏区、右侧详情栏；窄窗口详情栏排入页面，不遮挡游戏区。
- 导入工作区由“来源—内容预览—目标”三栏组成，窄窗口自然堆叠。
- 保留空列表、无封面、文件缺失、读取失败、正在处理和处理结果等可读状态。
- 静态界面支持中英文；游戏名、路径等用户数据保持原文。

## 本轮不包含

物理删除游戏文件、跨存储移动、存档管理、浏览器拖入文件上传和全新封面编辑器。导入保留源文件和原文件名；名称与封面可继续补全。BIOS 只作为依赖文件，不计入游戏列表。
