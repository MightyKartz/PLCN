# Application icon

Original vector source: [brand.svg](../../src/templates/brand.svg).

`app-icon.png` is the 1024×1024 RGBA export. `app-icon.ico` contains Windows sizes from 16 to 256 pixels, and `app-icon.icns` contains macOS icon sizes up to 1024 pixels. Update these exports together when changing the SVG. Desktop packaging consumes the checked-in exports; it does not require a graphics renderer at build time.
